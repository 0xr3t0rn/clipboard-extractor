# Phone Number and Email Extractor
Finds all valid phone numbers (e.g +639123456789) and email addresses from your clipboard and extract it.

## Usage
1. Create and activate virtual environment:
(If you're using python3)
```bash
python3 -m venv .venv
source .venv/bin/activate

2. Install dependencies:
```bash
python3 -m pip install pyperclip

2. Run the script:
```bash
python3 phone_email_extractor.py
